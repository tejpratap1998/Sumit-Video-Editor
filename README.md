## ✨ Features

- **4-Phase Fullscreen Cinematic Intro Loader**: Timeline bar animation, 35mm projector flicker, staggered letter drop, and hard razor-cut transition.
- **Three.js 3D Background Engine**: 2,200+ particle celestial universe with responsive mouse parallax & 3D floor grid.
- **Interactive Video Modal & Color Grading Comparison**: Real-time draggable split slider comparing flat RAW footage vs finished cinematic color grading.
- **Pinned Horizontal Showcase Reel**: Smooth GSAP ScrollTrigger timeline displaying top video editing projects with live timecode ticks.
- **Synthesized Web Audio API Sound Design**: Ambient drone, camera shutter clicks, whoosh transitions, and digital pips.
- **Direct WhatsApp Integration**: Instant chat link pre-configured with number `+91 7626874637`.
- **Fully Responsive**: Optimized for ultra-wide desktops, laptops, tablets, and smartphones.

## 🛠️ Tech Stack

- **Markup & Layout**: Semantic HTML5 & Vanilla CSS (Glassmorphism, CSS Grid, Flexbox, Custom Properties)
- **3D Graphics**: Three.js
- **Animations & Smooth Scroll**: GSAP 3 (ScrollTrigger) & Lenis Scroll
- **Audio**: Web Audio API (100% synthesized sound design)
- **Icons**: FontAwesome 6 Pro

## 🚀 Getting Started

### Local Development
Clone this repository and launch a local web server:

```bash
# Clone repository
git clone <your-repo-url>
cd "Sumit Video Editor"

# Start local server (Python)
python -m http.server 8080

# Or using Node
npx serve .
```

Visit `http://localhost:8080` in your web browser.
